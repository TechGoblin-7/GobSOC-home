# GobSOC-home
A Python-based home SOC (Security Operations Center) for system monitoring and log analysis, built with FastAPI and Docker in mind.

> A personal homelab project focused on IT operations, system monitoring, and security fundamentals.

A lightweight, Python-based Security Operations Center (SOC) designed for monitoring system metrics and logs across local environments.

## Overview
GobSOC Home simulates a simplified SOC environment by collecting telemetry from system agents and centralizing it through a FastAPI backend.

## Features (Planned)
- System metrics collection (CPU, RAM, Disk)
- Centralized logging
- Security event monitoring
- Dockerized deployment
- Real-time dashboard
